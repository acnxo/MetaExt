# 区域字典（Region）

> 所属：MetaExt 元数据字典 · 存放：`Meta/FTMM/Dict/Region.md`
> 用途：富途 / moomoo（FTMM）数据中 `region` 字段的取值字典——**区域原值为键，地区中文名为值**，
> 供证券、交易所、市场按区域归类、筛选与展示时统一口径。
> 数据来源：上游仓库 `FinvFutu/Dict/region.md` 的区域取值与样本统计（统计时点 `2026-06-15`，
> 共 **150,778** 条样本，覆盖 `region` 全部 **25** 个取值）。
> 关联：FinvQuant 规范化字典 `Meta/Dict/FinvRegion.md`——其 `region` 简写由本字典换算而来
> （`0`/`1` 分别对应 `UNK`/`GLOBAL`，`2`~`24` 对应 `CN`~`ID`）。

## 二、说明

- 键：`region` 字段的**原始取值**，十进制整数字符串，取值范围 `0`~`24`。
- 值：该取值对应的地区中文名称（规范名，如 `中国大陆`、`美国`）。
- 简码：FinvQuant 规范化的 `region` 简写（如 `CN`、`HK`），与本字典的原始数值不是同一套标识，
  跨系统对接时须显式换算。
- 排序：按原值升序。
- 编码规则：`0` = 未知/默认；`1` = 全球（笼统口径，涵盖外汇、加密货币与无地区归属品种）；
  `2`~`24` = 国家/地区，按富途自选股 region 原值连续排布。
- 主要按国家/地区划分，与 `exchange` 字段高度关联；`10`~`24` 以欧洲及其它小型市场为主。
- 使用提醒：`1` 只是笼统口径，FinvQuant 侧已按 `FX`（外汇）与 `CC`（加密货币）细分，
  新数据不要再用 `1` 代表具体类别。

## 三、维护约定

- 本文件描述的是**富途 / moomoo 侧的原始取值**，取值集合由上游决定；上游字典变更后同步本文件，
  不在此处自行裁剪或新增条目。
- 新增取值时保持原值升序，`2`~`100` 段为预留扩展位，编号不得插空或重排。
- 本表只记录「键 / 值 / 简码」三个口径；各地区的市场归属、代表性品种与样本分布回看上游
  `FinvFutu/Dict/region.md`，不在本文件展开，避免同一事实出现两处口径。
- 与 FinvQuant 字典的一致性核对：本表原值 `2`~`24` 的行数应恒为 23 行，
  且与 `Meta/Dict/FinvRegion.md` 中简码 `CN`~`ID` 的记录逐行对应。
- FinvQuant 侧改动简码（如 `USA`→`US`）属于跨表引用变更，须联动 `finv_exchange.region`、
  `finv_market.region` 与证券归一化逻辑，不能只改字典表。
