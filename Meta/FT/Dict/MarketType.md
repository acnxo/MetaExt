# 接口市场枚举字典（market_type / marketType）

> 所属：MetaExt 元数据字典 · 存放：`Meta/FT/Dict/MarketType.md`\
> 用途：moomoo quote-v2 **请求参数**里的市场编号字典——**编号为键，市场中文名为值**，\
> 响应侧的字符串标签见同行的 `market_label` 列。

## 一、字典表

| 键 | 值 | market_label |
|-----:|------|:---:|
| `1` | 港股 | `HK` |
| `2` | 美股 | `US` |
| `4` | 沪深京 A 股 | `SH` / `SZ` / `BJ` |
| `11` | 外汇 | `FX` |
| `15` | 新加坡 | `SG` |
| `17` | 加密货币 | `CC` |
| `22` | 澳大利亚 | `AU` |
| `25` | 日本 | `JP` |
| `27` | 马来西亚 | `BMS` |
| `30` | 加拿大 | `CA` |

## 二、说明

- 键：请求参数的**原始取值**，十进制整数字符串；同一套编号在 1101 写作 `market_type`、
  在 1103 / 1104 / 1106 / 1108 写作 `marketType`，字段名大小写敏感，取值完全相同。
- 值：市场中文名称。
- market_label：响应字段 `marketLabel` 的取值，见 [MarketLabel.md](MarketLabel.md)。
- 排序：按原值升序。
- 表内 10 个取值即服务端白名单，其余数值一律返回 `Params Error`，因此「能调通」不等于「取值正确」。
- `4` 覆盖沪深京 A 股，三地只能靠 `market_label` 区分。
- 与本地库字段不可互换：`cs_market`、`market_code` 都不能直接当 `marketType` 传。
- 前端还有 `QuoteMarketType` 细枚举与埋点编号两套体系，同一个数字含义不同（如 `4` 在接口是
  A 股、在细枚举是 `BD`），跨体系套用会得到错误结果。

## 三、维护约定

- 本文件描述的是**富途 / moomoo 侧的原始取值**，取值集合由上游决定；上游字典变更后同步本文件，
  不在此处自行裁剪或新增条目。
- 新增编号时按原值升序插入，并同时确认响应侧的 `marketLabel`。
